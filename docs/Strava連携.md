# Strava 連携

走行距離は Strava から取ります。取得は自動ではなく、ホームの「Strava同期」から同期画面で期間を指定して行います。

いま実装しているのは、**アプリ登録 → PC 上で認可 → トークンを端末に保存 → 同期画面から走行と自転車を取る**までです。Android での確認は、PC 上の動作確認が終わってからです。

同期画面のボタン配置は [画面設計](画面設計.md) を参照してください。期間は前回から 3か月 / 6か月 / 1年、または開始日です。開始日はデータの起点、何日までは開始日以降で入っているいちばん新しい走行の日です。開始日を変えると走行データを消して取り直します。

## 決まっていること

- アプリ起動だけでは取りに行かない
- 同期ボタンを押したときだけ取る
- 押すと同期画面へ切り替える
- 一度に全部は取らず、期間を区切る
- 同期した自転車（ギア）から、設定で集計対象を1台選ぶ
- 部品の走行距離は、選んだギアの走行だけを足す
- Client Secret はサーバーではなく、少人数アプリとして端末（と開発用のローカルファイル）に置く
- トークンは端末内の SQLite に保存する。Git には置かない

## PC 上で認可を試す手順

### 1. Strava にアプリを登録する

1. [https://developers.strava.com/](https://developers.strava.com/) を開いている場合は、**Create & Manage Your App** を押す。ログインしていなければ、使う Strava アカウントで入る。
2. [https://www.strava.com/settings/api](https://www.strava.com/settings/api)（My API Application）に進む。「Create App」で作る。  
   **2026-06-30 以降、Standard Tier の API 利用には Strava の有料サブスクリプションが必要です。** ページに出る Access Token が無料で使えるように見えても、連携や走行取得はサブスクなしでは止まります。すでに有料なら追加料金はありません。同じアカウントでログインしてから「連携する」をやり直してください。
3. 次を入れる

| 項目 | 値 |
| --- | --- |
| Application Name | GearDoctor（任意） |
| Category | 任意（Lifestyle など） |
| Club | 空でよい |
| Website | `http://127.0.0.1` でよい |
| **Authorization Callback Domain** | `127.0.0.1` |

パスやポートは Domain 欄には書きません。`http://` も付けません。

4. 登録後に表示される **Client ID** と **Client Secret** を控える。Secret は Git に載せない

### 2. アプリに Client ID / Secret を渡す

どれか一つで足ります。

**A. Strava 連携画面に直接入力（いちばん簡単）**

アプリを起動し、設定の「Strava 連携」を開いて Client ID / Client Secret に貼る。連携方法は同じ画面の「連携を解除」の下にあります。

**B. リポジトリ直下のファイル（毎回入力したくないとき）**

```
cp strava_secrets.example.json strava_secrets.json
```

`strava_secrets.json` を自分の値に書き換える。このファイルは `.gitignore` 済みです。

**C. 環境変数**

```
export STRAVA_CLIENT_ID=12345
export STRAVA_CLIENT_SECRET=xxxxxxxx
```

### 3. PC で連携する

リポジトリのフォルダで:

```
flutter run -d linux
```

1. 設定の「Strava 連携」を開く
2. Client ID と Secret が入っていることを確認する
3. 「連携する」を押す
4. ブラウザで Strava にログインし、権限を許可する
5. 成功すると「連携済み」と自分の名前が出る

戻り先は次に固定しています。

```
http://127.0.0.1:8742/callback
```

WSL では、Linux 側から Chrome を開けないことがあります。Strava 連携画面の「許可用 URL をコピー」を **PC の Chrome のアドレス欄に貼って** 開いてください。エクスプローラのフォルダが開いた場合は、URL が途中で切れた古い開き方です。無視して、コピーした URL を Chrome に貼ります。

許可したあとアプリに戻らないときは、ブラウザのアドレス欄（`callback?code=...`）を同じ画面の貼り付け欄に入れて「貼ったコードで続ける」を押します。`{"message":"error"}` だけ出たタブは閉じてください。許可用 URL ではありません。

成功の目安:

- Strava 連携画面が「連携済み」になる
- 自分の Strava 表示名が出る
- プロフィールに自転車があれば、ギアの一覧に名前が出る
- アプリを終了して起動し直しても「連携済み」のまま（トークンが端末に残っている）

「連携を解除」でトークンを消し、可能なら Strava 側も無効化します。

### 4. 走行を取る

連携済みなら、ホームの「Strava同期」から期間を選んで走行を取ります。開始日が無いときは先に指定します。デモの走行は、最初の取得で消して Strava の内容に置き換えます。

まだやらないこと:

- Android 実機での OAuth（カスタム URL スキームが必要）

## 制限（確認済み）

2026-08 時点の Standard Tier（表示されていた値）:

| 種類 | 15 分 | 1 日 |
| --- | --- | --- |
| 総合 | 200 | 2,000 |
| 読み取り | 100 | 1,000 |

制限はアプリ単位です。人数が少なければ、ほぼ一人で使えます。15 分枠は時計の 0 / 15 / 30 / 45 分でリセットされるのが通例です。1 日は UTC 深夜でリセットです。

GearDoctor が同期で使うのは主に次の読み取りです。

- 自転車一覧: `GET /athlete`（1 回）
- 走行一覧: `GET /athlete/activities`（1 回で最大 200 件。日付・距離・`gear_id` が付く）

走行の詳細や GPS（streams）は取らない想定なので、**効くのは読み取り上限**です。

| 取り方 | 15 分 | 1 日 |
| --- | --- | --- |
| 一覧だけ（200 件/回） | 約 20,000 走行 | 約 200,000 走行 |
| 走行ごとに詳細を 1 回 | 100 走行 | 1,000 走行 |

実例（一覧だけ）:

- 週 2〜4 回乗る人 → 年 100〜200 走行 → **1 年分で 1 回**
- 10 年分（1,000〜2,000 走行）→ **5〜10 回 + ギア 1 回**
- 「前回から 3 か月」→ **1 回**

一人で部品管理する用途なら、初回の全期間でも 15 分枠に収まります。期間ボタン（3 か月 / 6 か月 / 1 年）は、失敗したときのやり直しを小さくするためにも残します。詳細 API や streams を足すと、すぐ 1,000 走行/日に近づきます。
