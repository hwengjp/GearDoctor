# 画面設計

色や装飾は後回しです。確認用のワイヤーフレームはチャット横の Canvas にあります。ソースは [`canvases/ui-wireframe.canvas.tsx`](../canvases/ui-wireframe.canvas.tsx) です。

## 決まったこと

- 下部タブは置かない
- 「交換した」は詳細画面だけ
- 詳細の「交換した」ボタンの下に、その部品の過去の交換記録を出す（ギアの走行距離・交換日・コメント）。ギアの走行距離は開始日からの積算。交換日に走行がなくても、その日までの積算を出す。一番下は今日までの積算で、距離に（今日）を付け、交換日は空欄
- 交換日は初期値を今日にし、記録し忘れのときは別の日に直せる
- 「交換した」画面では、記録ボタンの下にも同じ過去の交換記録を出す
- 交換記録には任意のコメントを付けられる。履歴表にも出す
- 過去の交換記録は行をタップして、日付の修正・コメントの修正・削除ができる
- ホームで一番大きいボタンは「Strava同期」
- 同期は自動では行わない。押したときだけ取りに行き、同期画面へ切り替える
- 同期の期間は、前回から 3 か月 / 6 か月 / 1 年、または開始日
- 開始日はデータの起点。何日までは開始日以降で入っているいちばん新しい走行の日（同期した日ではない）
- 開始日を変えると走行データを消す。開始日から何日まで抜けなく取るため
- 最初の部品はタイヤ、チェーン、ブレーキパッド、ワイヤー、ブレーキオイル、ディスク、バーテープ、センサ・ライトの電池、プーリー
- 交換周期は距離（km）か月、部品ごとにどちらか一方。日指定はしない。しきい値は選んだ周期に対する％
- 部品は登録名だけで管理する。追加に単独 / F / R の種別は付けない
- 左右の合体は表示のまとめだけ。まとめた名前は表示専用で、登録名とは合わせない
- ホームでスクロールするのは部品一覧だけ。警告と同期ボタンは固定
- デモ走行があるあいだ、ホームの GearDoctor 直下に「デモを解除するには Strava を同期します」を出す。しきい値バナーと同じ枠。タップで同期画面。最初の実同期で消える
- 「部品を追加」は設定の中
- Strava の連携は設定から専用画面を開く。連携方法の説明は「連携を解除」の下
- 設定の「初期状態に戻す」は確認のうえ、Strava の連携と走行、部品の設定と交換記録を消し、初回と同じデモ状態に戻す
- 交換記録の CSV は、既存の登録名にだけ取り込む。書き出しも同じ形式。部品は作らない。交換日が空の行は開始日。CSV に出てきた登録名は、いまの交換記録を消して差し替える
- 部品を追加したときの最初の交換日は開始日（まだ無いときは今日）。入力欄は置かない
- しきい値の警告は件数と、タップできる名前の並び。1件でも同じ形
- 走行距離の集計対象ギアは、Strava 同期で得た自転車から設定で選ぶ
- ホーム上部は「ギア: Aeroad」と「最終同期 2025-07-17〜2026-07-15」を横に並べる
- 初回のデモ走行・デモギアがあるあいだは、ギア名・最終同期・距離の値の末尾に「（デモ）」を付ける。月の経過には付けない。最初の実同期でデモ走行が消えると印も消える
- 交換目安は推奨、前回交換周期から計算、設定の三択。進捗に使うのは選んだ一方。前回周期は毎回、記録と走行から計算する。交換が2回以上なら直近とその一つ前のあいだ。1回だけなら開始日からその交換まで
- 同期画面は開始日と何日までの両方を出す

## ホームのイメージ

前後がある部品は、自転車を左から見て右が進行方向、という向きです。左が R、右が F。左右は別々にタップして詳細へ進みます。

```
GearDoctor                          設定
デモを解除するには Strava を同期します。
最初の取得でデモ走行は消えます。        ← デモ中だけ。タップで同期画面
ギア: Aeroad（デモ）            最終同期 2025-07-17〜2026-07-15（デモ）

しきい値 2件
[タイヤ F]  [ブレーキパッド F]   ← タップで詳細へ

        ↑ ここから下の部品だけスクロール
┌ タイヤ                                        ┐
│ R：余裕・45％          │ F：そろそろ・80％     │
│ 2700km（デモ）          │ 4800km（デモ）        │
│ ████░░░░               │ ████████████░░        │
└───────────────────────────────────────────────┘
┌ チェーン                                      ┐
│ 余裕・45％                                    │
│ 1800km（デモ）                                 │
└───────────────────────────────────────────────┘
┌ ブレーキパッド / ワイヤー / ブレーキオイル / ディスク もタイヤと同じ左右   ┐
┌ スピードセンサ電池                            ┐
│ 余裕・58％                                    │
│ 7か月                                         │
└───────────────────────────────────────────────┘
        ↓ ここまで
[        Strava同期        ]   ← 固定
```

まとめ表示のカードは表示名（例: タイヤ）で、左が R、右が F です。分けて表示すると、各カードは登録名（例: 前タイヤ、後タイヤ）で出ます。記録は独立したままです。登録名と表示名に差ができても、自動では合わせません。

チェーンは単独なので、まとめません。

## 交換を記録

初期値は今日です。記録し忘れのときは、交換日を実際の日に直してから記録します。距離はその日以降の走行から数え直します。

```
戻る                    交換を記録

タイヤ（F）を交換した日付を記録すると、
この位置の走行距離だけゼロから始まります。

交換日
[ 2026-08-23 ]          ← タップして修正
初期値は今日。記録し忘れのときは実際の日に直す

メモ
[ 製品名、交換理由など（空でも可） ]

[ 記録する ]

過去の交換記録   ← 行をタップして編集
ギアの走行距離     交換日       コメント
5,800km（デモ）   2023-04-02  —
11,900km（デモ）  2024-01-15  パンク後に交換
16,700km（デモ）  2025-03-01  GP5000
21,500km（今日）

[ キャンセル ]
```

記録を編集:

```
戻る                    記録を編集

タイヤ（F） · 4,800 km

交換日
[ 2025-03-01 ]

メモ
[ GP5000 ]

日付を変えると、その期間の走行距離を数え直す

[ 保存 ]
[ この記録を削除 ]
[ キャンセル ]
```

## 部品を追加

設定から開きます。追加は常に1件で、付けるのは登録名だけです。単独 / F / R の種別はありません。左右を1カードに見せるのは「表示のまとめ」です。

```
登録名
[ 前タイヤ                  ]
```

交換周期は距離か月の二択で、同時には使わない。

```
交換周期
[ 距離 ]  [ 月 ]
```

月を選んだ例（スピードセンサ電池）:

```
交換目安
┌ 推奨  12 か月 ┐
┌ 前回交換周期から計算  — ┐
┌ 設定  12 か月 ┐
```

距離を選んだ例（ブレーキオイル）:

```
交換目安
┌ 推奨  10,000 km ┐
┌ 前回交換周期から計算  8,200 km ┐
┌ 設定  10,000 km ┐
```

## 交換目安

追加・編集で、推奨・前回交換周期から計算・設定を並べて一つを選びます。三つの数値は常に見えます。進捗に使うのは選んだ一方だけです。ホームのカードには種別を出さず、詳細に「推奨」「前回周期」「設定」と付けます。前回周期は毎回、交換記録と走行から計算します。保存した固定値ではありません。交換が2回以上あれば、直近とその一つ前の交換のあいだの距離または月です。1回だけなら、開始日からその交換までです。開始日より前の走行は入りません。積算のギア走行距離（例: 16,227 km）そのものではありません。

```
交換目安
┌ 推奨  6,000 km                    ┐  ← 名前から自動で決まります
└───────────────────────────────────┘
┌ 前回交換周期から計算  4,800 km    ┐  ← 直近の2回の間隔。毎回計算
└───────────────────────────────────┘
┌ 設定  5,000 km                    ┐  ← 自分で入力します
└───────────────────────────────────┘
```

詳細では分母の横に、今使っている方を出します。

```
4,800 / 6,000 km
80% · そろそろ     推奨 · しきい値 80%
```

## 表示のまとめ

内部の処理は登録名だけです。まとめた名前はホーム用の表示名で、登録名とは別です。差ができても合わせこみはしません。

**分けて表示**

まとめを解除し、2カードを登録名のまま出します。末尾に F/R を付ける改名はしません。

**まとめて表示**

登録名の違う2件を1カードにします。次の3つを指定します。

1. まとめる2つの部品（登録名で選ぶ）
2. どちらが F か（残りが R。左が R、右が F）
3. カードの表示名（例: タイヤ）

```
表示のまとめ

1. 2つの部品を選ぶ
   [前タイヤ]  [後タイヤ]

2. どちらが F か
   [ 前タイヤ が F ]

3. まとめた名前
   [ タイヤ ]

ホームは「タイヤ」。左が R、右が F
```

## Strava 連携

設定の「Strava 連携」から開きます。連携方法の説明は「連携を解除」の下です。

```
戻る                    Strava 連携

未連携 / 連携済み
Client ID
Client Secret
[ 連携する ]
[ 連携を解除 ]

連携方法
1. Strava の API 設定でアプリを作る
2. Callback Domain は 127.0.0.1
3. Client ID と Secret を上に入れる。このアプリでは Access Token は使いません
4. 「連携する」を押し、ブラウザで許可する
5. 戻らないときは、「連携する」のあとに出る欄へアドレス欄を貼る
```

走行の取得はホームの「Strava同期」からです。連携画面では手順だけを書きます。

## ギアの選択

設定で選びます。候補は Strava 同期で得た自転車（例: Aeroad、Endurace）です。部品の走行距離は、選んだギアの走行だけを足します。

同期する前は候補が空です。先に同期してから選びます。

## 初期化

設定の一番下です。確認ダイアログのあと、Strava の連携と走行、部品の設定と交換記録を消し、初回起動と同じデモ状態に戻します。

```
初期状態に戻しますか？

Strava の連携と走行、部品の設定と交換記録をすべて消します。

初回起動と同じデモ状態に戻ります。

[ キャンセル ]  [ 消して戻す ]
```

## 同期画面

ホームの同期を押すと、この画面に切り替わります。起動時や裏での自動取得はしません。

前回取った範囲は開始日と何日までの両方を出します。何日までは同期した日ではなく、開始日以降で入っているいちばん新しい走行の日です。

```
データの範囲
開始日  2025-07-17（デモ）
何日まで  2026-07-15（デモ）
```

開始日を指定・変更すると、走行データを消す確認を出します。開始日から何日まで抜けなく取れている必要があるためです。途中で開始日だけ変えると、取得に抜けが出ることがあります。

期間ボタンは、取り終えた日（まだなければ開始日）から先を足します。何日までは開始日以降で入っているいちばん新しい走行の日です。相対期間は N か月、今日までです。

- 前回から 3 か月
- 前回から 6 か月
- 前回から 1 年
- 開始日を指定 / 変更（確認のうえ走行データを消す）

候補として挙がっているが、まだ置かないもの:

- 取得の単位や失敗時のやり直し

詳細は [Strava 連携](Strava連携.md) に残します。

## 交換記録の CSV

設定の「交換記録の CSV」から、いまの記録を書き出せます。取り込みも同じ画面です。「例を入れる」は初期部品の登録名を全部出し、交換日は開始日です。空欄の交換日も開始日になります。部品は作りません。まとめ表示の名前ではなく登録名で結びます。CSV に出てきた登録名は、デモの初期日も含めていまの交換記録を消し、CSV の日付で差し替えます。同じ CSV 内の同じ部品・同じ日だけ飛ばします。

```
登録名,交換日,メモ
前タイヤ,2025-03-01,GP5000
後タイヤ,2025-08-01,サイドカット
```
