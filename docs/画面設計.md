# 画面設計

色や装飾は後回しです。確認用のワイヤーフレームはチャット横の Canvas にあります。ソースは [`canvases/ui-wireframe.canvas.tsx`](../canvases/ui-wireframe.canvas.tsx) です。

## 決まったこと

- 下部タブは置かない
- 「交換した」は詳細画面だけ
- 詳細の「交換した」ボタンの下に、その部品の過去の交換記録を出す（ギアの走行距離・交換日・コメント）。ギアの走行距離はそのギアの最初の走行日からの積算。交換日に走行がなくても、その日までの積算を出す。一番下は今日までの積算で、距離に（今日）を付け、交換日は空欄
- 交換日は初期値を今日にし、記録し忘れのときは別の日に直せる
- 「交換した」画面では、記録ボタンの下にも同じ過去の交換記録を出す
- 交換記録には任意のコメントを付けられる。履歴表にも出す
- 過去の交換記録は行をタップして、日付の修正・コメントの修正・削除ができる
- ホームで一番大きいボタンは「Strava同期」
- 同期は自動では行わない。押したときだけ取りに行き、同期画面へ切り替える
- 同期の期間は、前回から 3 か月 / 6 か月 / 1 年、または Strava開始日
- Strava開始日は、Strava から走行を取る起点。何日までは Strava開始日以降で入っているいちばん新しい走行の日（同期した日ではない）
- Strava開始日を変えると走行データを消す。Strava開始日から何日まで抜けなく取るため
- 最初の部品はタイヤ、チェーン、ブレーキパッド、ワイヤー、ブレーキオイル、ディスク、バーテープ、センサ・ライトの電池、プーリー
- 交換周期は距離（km）か月、部品ごとにどちらか一方。日指定はしない。しきい値は選んだ周期に対する％
- 部品は登録名だけで管理する。追加に単独 / F / R の種別は付けない
- 左右の合体は表示のまとめだけ。まとめた名前は表示専用で、登録名とは合わせない
- ホームでスクロールするのは部品一覧だけ。警告と同期ボタンは固定
- デモ走行があるあいだ、ホームの GearDoctor 直下に「デモを解除するには Strava を同期します」を出す。しきい値バナーと同じ枠。タップで同期画面。最初の実同期で消える
- デモのあいだは部品の追加と記録の CSV はエラーにする。「先に Strava を同期してください」と出す。同期するまで入れられない
- 「部品を追加」「記録の CSV」「表示をまとめる / 分ける」はギア画面の中。ホームのギア名をタップして開く。設定からもギア画面へ行ける
- Strava の連携は設定から専用画面を開く。連携方法の説明は「連携を解除」の下。設定から Strava同期とギア画面にも行ける
- 設定の「初期状態に戻す」は確認のうえ、Strava の連携と走行、部品の設定と交換記録を消し、初回と同じデモ状態に戻す
- 設定のいちばん下に `GearDoctor 1.0.0` を出す。APK を作るたびに版を 0.0.1 ずつ上げる
- 部品を追加したときの最初の交換日は、選んでいるギアのいちばん古い走行日。入力欄は置かない。走行がまだ無いときは今日
- その日の始まり（0:00）を起点にする。同じ日の走行は距離に入り、その日自体も期間の初日になる
- 前提は、そのギアで走り始める前に部品を最新にしていた、こと。最初の走行日＝いま乗っている部品の起点
- 同期の「Strava開始日」（いつから取るか）と、部品の起点（そのギアの最初の走行日）は別。部品の距離・月・自動周期は後者を使う
- 交換記録はギアごと。部品の設定・追加・表示のまとめもギアごと。初期の部品は同じ。Strava から取った自転車が無いと、そのギアの交換記録も CSV も入力できない。ギアを選んでから、CSV と交換記録が使える
- 記録の CSV は、選んだギアの記録だけを出し入れする。既存の登録名にだけ取り込む。書き出しも同じ形式。部品は作らない。交換日が空の行は、そのギアの最初の走行日（まだ無いときは今日）。CSV に出てきた登録名は、そのギアのいまの交換記録を消して差し替える。他のギアの記録はそのまま
- しきい値の警告は件数と、タップできる名前の並び。1件でも同じ形
- 走行距離の集計対象ギアは、Strava 同期で得た自転車からギア画面で選ぶ
- ホーム上部は「ギア: Aeroad」と「最終同期 2025-07-17〜2026-07-15」を横に並べる。ギア名は少し大きく、タップでギア画面。最終同期はタップで同期画面
- 初回のデモ走行・デモギアがあるあいだは、ギア名・最終同期・距離の値の末尾に「（デモ）」を付ける。月の経過には付けない。最初の実同期でデモ走行が消えると印も消える
- 交換目安は推奨、自動、設定の三択。進捗に使うのは選んだ一方。自動は毎回、記録と走行から計算する。交換が2回以上なら直近とその一つ前のあいだ。1回だけなら、そのギアの最初の走行日からその交換まで
- ホームの距離・か月は、使った量 / 交換目安と種別（推奨 / 自動 / 設定）を出す
- 同期画面は Strava開始日と何日までの両方を出す

## ホームのイメージ

前後がある部品は、自転車を左から見て右が進行方向、という向きです。左が R、右が F。左右は別々にタップして詳細へ進みます。

```
GearDoctor                          設定
デモを解除するには Strava を同期します。
最初の取得でデモ走行は消えます。        ← デモ中だけ。タップで同期画面
ギア: Aeroad（デモ）            最終同期 2025-07-17〜2026-07-15（デモ）
        ↑ タップでギア画面              ↑ タップで同期画面

しきい値 2件
[タイヤ F]  [ブレーキパッド F]   ← タップで詳細へ

        ↑ ここから下の部品だけスクロール
┌ タイヤ                                        ┐
│ R：余裕・45％          │ F：そろそろ・80％     │
│ 2,700 / 6,000 km 推奨（デモ） │ 4,800 / 6,000 km 推奨（デモ） │
│ ████░░░░               │ ████████████░░        │
└───────────────────────────────────────────────┘
┌ チェーン                                      ┐
│ 余裕・45％                                    │
│ 1,800 / 4,000 km 推奨（デモ）                  │
└───────────────────────────────────────────────┘
┌ ブレーキパッド / ワイヤー / ブレーキオイル / ディスク もタイヤと同じ左右   ┐
┌ スピードセンサ電池                            ┐
│ 余裕・58％                                    │
│ 7 / 12 か月 推奨                              │
└───────────────────────────────────────────────┘
        ↓ ここまで
[        Strava同期        ]   ← 固定
```

まとめ表示のカードは表示名（例: タイヤ）で、左が R、右が F です。分けて表示すると、各カードは登録名（例: 前タイヤ、後タイヤ）で出ます。記録は独立したままです。登録名と表示名に差ができても、自動では合わせません。

チェーンは単独なので、まとめません。

## 交換を記録

初期値は今日です。記録し忘れのときは、交換日を実際の日に直してから記録します。距離はその日以降の走行から数え直します。

```
戻る                    交換を記録

タイヤ（F）を交換した日付を記録すると、
この位置の走行距離だけゼロから始まります。

交換日
[ 2026-08-23 ]          ← タップして修正
初期値は今日。記録し忘れのときは実際の日に直す

メモ
[ 製品名、交換理由など（空でも可） ]

[ 記録する ]

過去の交換記録   ← 行をタップして編集
ギアの走行距離     交換日       コメント
5,800km（デモ）   2023-04-02  —
11,900km（デモ）  2024-01-15  パンク後に交換
16,700km（デモ）  2025-03-01  GP5000
21,500km（今日）

[ キャンセル ]
```

記録を編集:

```
戻る                    記録を編集

タイヤ（F） · 4,800 km

交換日
[ 2025-03-01 ]

メモ
[ GP5000 ]

日付を変えると、その期間の走行距離を数え直す

[ 保存 ]
[ この記録を削除 ]
[ キャンセル ]
```

## 部品を追加

ギア画面から開きます。Strava から自転車を取って選んでいないときは追加できません。追加は常に1件で、付けるのは登録名だけです。単独 / F / R の種別はありません。左右を1カードに見せるのは「表示のまとめ」です。

```
登録名
[ 前タイヤ                  ]
```

交換周期は距離か月の二択で、同時には使わない。

```
交換周期
[ 距離 ]  [ 月 ]
```

月を選んだ例（スピードセンサ電池）:

```
交換目安
┌ 推奨  12 か月 ┐
┌ 自動  — ┐
┌ 設定  12 か月 ┐
```

距離を選んだ例（ブレーキオイル）:

```
交換目安
┌ 推奨  10,000 km ┐
┌ 自動  8,200 km ┐
┌ 設定  10,000 km ┐
```

## 交換目安

追加・編集で、推奨・自動・設定を並べて一つを選びます。三つの数値は常に見えます。進捗に使うのは選んだ一方だけです。ホームと詳細の距離・か月には、使った量 / 交換目安と種別（推奨 / 自動 / 設定）を出します。自動は毎回、交換記録と走行から計算します。保存した固定値ではありません。交換が2回以上あれば、直近とその一つ前の交換のあいだの距離または月です。1回だけなら、そのギアの最初の走行日からその交換までです。その日より前の走行は入りません。積算のギア走行距離（例: 16,227 km）そのものではありません。

```
交換目安
┌ 推奨  6,000 km                    ┐  ← 名前から自動で決まります
└───────────────────────────────────┘
┌ 自動  4,800 km                    ┐  ← 直近の2回の間隔。毎回計算
└───────────────────────────────────┘
┌ 設定  5,000 km                    ┐  ← 自分で入力します
└───────────────────────────────────┘
```

詳細では分母の横に、今使っている方を出します。

```
4,800 / 6,000 km
80% · そろそろ     推奨 · しきい値 80%
```

## 表示のまとめ

ギア画面から開きます。内部の処理は登録名だけです。まとめた名前はホーム用の表示名で、登録名とは別です。差ができても合わせこみはしません。

**分けて表示**

まとめを解除し、2カードを登録名のまま出します。末尾に F/R を付ける改名はしません。

**まとめて表示**

登録名の違う2件を1カードにします。次の3つを指定します。

1. まとめる2つの部品（登録名で選ぶ）
2. どちらが F か（残りが R。左が R、右が F）
3. カードの表示名（例: タイヤ）

```
表示のまとめ

1. 2つの部品を選ぶ
   [前タイヤ]  [後タイヤ]

2. どちらが F か
   [ 前タイヤ が F ]

3. まとめた名前
   [ タイヤ ]

ホームは「タイヤ」。左が R、右が F
```

## Strava 連携

設定の「Strava 連携」から開きます。連携方法の説明は「連携を解除」の下です。

```
戻る                    Strava 連携

未連携 / 連携済み
Client ID
Client Secret
[ 連携する ]
[ 連携を解除 ]

連携方法
1. Strava の API 設定でアプリを作る
2. Callback Domain は 127.0.0.1
3. Client ID と Secret を上に入れる。このアプリでは Access Token は使いません
4. 「連携する」を押し、ブラウザで許可する
5. 戻らないときは、「連携する」のあとに出る欄へアドレス欄を貼る
```

走行の取得はホームの「Strava同期」からです。連携画面では手順だけを書きます。

## ギアの選択

ホームのギア名、または設定の「ギア」から開きます。候補は Strava 同期で得た自転車（例: Aeroad、Endurace）です。Strava に無い自転車の交換記録は作れません。部品の走行距離は、選んだギアの走行だけを足します。交換記録と CSV も、選んだギアだけです。

ギア画面のいちばん上に、選んでいる自転車の名前を大きく出します。その下で自転車を選び、部品を追加、記録の CSV、表示をまとめる / 分ける、を開きます。選ぶまでは CSV も交換記録も入力できません。部品の追加と設定の変更は、選んだギアにだけ効きます。初期の部品はどの自転車も同じです。

部品の最初の交換日は、そのギアのいちばん古い走行日です。走り始める前に部品を最新にしていた、という前提です。起点はその日の 0:00 なので、その日の距離も日数も入ります。

同期する前は候補が空です。先に同期してから選びます。

```
戻る                            ギア

Aeroad（デモ）                  ← 大きめ

Strava から取った自転車だけ選べます。
部品の追加・設定、交換記録、CSV は選んだギアだけです。
初期の部品は同じです。
デモのあいだは部品の追加と記録の CSV は使えません。
先に Strava を同期してください。

[ Aeroad（デモ・選択中） ]
[ Endurace（デモ） ]
[ Grail（デモ） ]

[ 部品を追加 ]
[ 記録の CSV ]
[ 表示をまとめる / 分ける ]
```

設定の操作のいちばん下です。確認ダイアログのあと、Strava の連携と走行、部品の設定と交換記録を消し、初回起動と同じデモ状態に戻します。ボタンの下に、いまの版を `GearDoctor 1.0.0` の形で出します。APK を作るたびに 0.0.1 ずつ上がります。

```
初期状態に戻しますか？

Strava の連携と走行、部品の設定と交換記録をすべて消します。

初回起動と同じデモ状態に戻ります。

[ キャンセル ]  [ 消して戻す ]
```

## 同期画面

ホームの同期を押すと、この画面に切り替わります。起動時や裏での自動取得はしません。

前回取った範囲は Strava開始日と何日までの両方を出します。何日までは同期した日ではなく、Strava開始日以降で入っているいちばん新しい走行の日です。

```
データの範囲
Strava開始日  2025-07-17（デモ）
何日まで  2026-07-15（デモ）
```

Strava開始日を変えると、取り込んだ走行は消えて初期化されます。新しい日から取り直します。

Strava開始日を指定・変更すると、走行データを消す確認を出します。Strava開始日から何日まで抜けなく取れている必要があるためです。途中で Strava開始日だけ変えると、取得に抜けが出ることがあります。

期間ボタンは、取り終えた日（まだなければ Strava開始日）から先を足します。何日までは Strava開始日以降で入っているいちばん新しい走行の日です。相対期間は N か月、今日までです。

- 前回から 3 か月
- 前回から 6 か月
- 前回から 1 年
- Strava開始日を指定 / 変更（変えると取り込んだ走行は消えて初期化。確認のうえ取り直す）

候補として挙がっているが、まだ置かないもの:

- 取得の単位や失敗時のやり直し

詳細は [Strava 連携](Strava連携.md) に残します。

## 記録の CSV

ギア画面の「記録の CSV」から、選んだギアのいまの記録を書き出せます。取り込みも同じ画面です。上にギア名を大きく出します。ギアが決まっていないときは入力できません。「例を入れる」は初期部品の登録名を全部出し、交換日はそのギアの最初の走行日です。空欄の交換日も同じです。部品は作りません。まとめ表示の名前ではなく登録名で結びます。CSV に出てきた登録名は、そのギアのいまの交換記録を消し、CSV の日付で差し替えます。他のギアの記録はそのままです。同じ CSV 内の同じ部品・同じ日だけ飛ばします。

```
登録名,交換日,メモ
前タイヤ,2025-03-01,GP5000
後タイヤ,2025-08-01,サイドカット
```

## まだ決めていないこと

- 同期の失敗時のやり直し
