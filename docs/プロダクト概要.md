# プロダクト概要

GearDoctor は、交換した自転車部品と走行距離から、次の交換時期を知らせるアプリです。対象は公開の利用者ではなく、開発者本人と親しい自転車仲間だけです。

## 誰向けか

- 自分の自転車の消耗品を、感覚ではなく走行距離で管理したい人
- Strava に走行を残している人
- 人数は少なく、互いに顔が見える関係

アプリストアには出しません。知らない人の登録も想定しません。

## 解決する課題

タイヤやチェーンは「そろそろかな」で交換しがちです。交換した日と、その後の走行距離が分かれば、目安（例: 6,000 km）と自分で決めたしきい値（例: 80%）で「そろそろ交換」と判断できます。

## できること（最初の範囲）

- 部品（タイヤ、チェーン、ブレーキパッド、ワイヤー）と、交換した時期を記録する
- 部品は登録名で1件ずつ記録する。左右を1カードに見せるのは表示のまとめだけ
- Strava から走行記録を、同期画面で期間を指定して読む
- 同期した自転車（ギア）をギア画面で選び、その走行だけを部品の距離に足す。部品の設定・追加と交換記録はギアごと。初期の部品は同じ。部品の最初の交換日は、そのギアのいちばん古い走行日（走り始める前に部品を最新にしていた前提）
- 部品ごとに交換周期を距離（km）か月で選び（排他）、交換目安は推奨・自動・設定の三択にし、しきい値を置く
- アプリを開いたときに、しきい値に達していれば知らせる

プッシュ通知は後回しにします。理由は [技術選定](技術選定.md) を参照してください。

最初の部品はタイヤ、チェーン、ブレーキパッド、ワイヤー、ブレーキオイル、ディスク、バーテープ、センサ・ライトの電池、プーリーです。登録名と表示のまとめ、周期（距離 / 月）は [画面設計](画面設計.md) を参照してください。

## 配布

サーバーは置かず、Android の APK を渡します。入れ方の詳細は [開発と配布](開発と配布.md) を参照してください。Google Play に載せる場合の手順は [Google Play 公開](GooglePlay公開.md) です。

| 何を渡すか | 手段 | 誰向け |
| --- | --- | --- |
| ソースコード | 非公開の Git リポジトリ | 開発する人 |
| アプリ本体 | Git 上の APK | Android で使う人 |

iPhone は同じソースからビルドできますが、ストアなしで仲間の端末へ入れる手段が重いため、主対象は Android です。

## やらないこと（今は）

- 不特定多数向けの公開
- アプリストアへの掲載
- 販売、課金
- ショップや在庫との連携

## 次に決めること

残件は同期の失敗時のやり直しと、Android での OAuth 確認です。詳細は [画面設計](画面設計.md) と [Strava 連携](Strava連携.md) を参照してください。
